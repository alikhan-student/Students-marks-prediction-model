# Student Marks Prediction 📊
A simple linear regression project that predicts student exam scores based on the number of hours studied.

## Overview
This project demonstrates a fundamental machine learning workflow using a synthetic dataset that models the relationship between study hours and exam performance.

## Features
- Data generation/loading and preprocessing
- Train-test split
- Linear regression model training using scikit-learn
- Model evaluation (R² score, MAE, MSE)
- Visualization of the regression line

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
